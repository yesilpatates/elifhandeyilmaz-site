SigortaGuru — Web & Interface

Logo and brand identityUI/UX designResponsive web designWordPress developmentContent and page structure

Project and brief

The SigortaGuru corporate website focuses on presenting insurance services in a clear and user-friendly structure. Helping visitors discover services and move towards a quotation process are central aims. Brand identity, written content and page structure are treated as parts of one digital experience, with the interface considered beyond its visual appearance alone.

Interface and content approach

The responsive structure is designed to support a consistent experience on desktop and mobile screens. Service grouping, content order and navigation areas come together in a straightforward interface. A trust-focused visual language and clear contact areas support the visitor’s next step. The presentation image shows the desktop and mobile designs together, making their shared brand approach visible.

Project scope

The project scope includes logo and brand identity, UI/UX design, responsive web design, WordPress development, page structure, content writing and visual composition. Considering the identity alongside the service copy supports a common language across the pages. Showing desktop and mobile screens together allows the interface to be reviewed in different viewing contexts.
