Event and brief

The presentation for the 5th Türkiye Maritime Summit explores a consistent event identity across different settings. Stage graphics, a roll-up, a flag, a programme, table signage and a participant badge are shown within the same visual system. The project extends beyond a single poster to show a family of applications that can be recognized throughout the event environment.

Visual system

The main mockup combines a dark navy background, gold-toned headings and maritime motifs. Anchors, a ship’s wheel and wave lines connect the graphics to the subject of the summit. The main title, date and location follow a consistent structure across the applications. Carrying the same identity from the large stage surface to smaller printed pieces is central to the presentation.

Applications and archive

The presentation brings stage graphics and attendee materials together in one composition. The broad stage composition and the narrower information area on a badge show how the same elements can be arranged at different scales. The programme and signage also illustrate how the identity extends from decorative surfaces to materials that communicate practical event information.
